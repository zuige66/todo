## ① 计算机软件著作权登记

### 去哪

https://www.ccopyright.com.cn （中国版权保护中心，唯一官方机构）

⚠️ 别在搜索引擎里点广告进"XX 代办"，那些收 300~800 元，官方是免费的。

### 怎么做

1. **注册账号** → 选择「个人」
2. **实名认证** —— 上传身份证正反面，做人脸核验
3. **在线填报** → 「软件著作权登记」→「我要登记」
4. **填写软件信息**：

| 字段 | 填什么 |
|---|---|
| 软件全称 | **一句话待办** |
| 软件简称 | 可留空 |
| 版本号 | **V1.0** |
| 开发完成日期 | 实际完成日（2026 年 10 月） |
| 首次发表日期 | 选「未发表」（未在商店上架就算未发表，更简单） |
| 权利取得方式 | 原始取得 |
| 权利范围 | 全部权利 |
| 开发方式 | 独立开发 |

5. **上传三份材料**（都是 PDF）

**已经给你生成好了两份，直接用：**

| 文件 | 页数 | 说明 |
|---|---|---|
| `dist/store/01-一句话待办-源程序.pdf` | 60 页 | 每页 50 行，页眉「一句话待办 V1.0」+ 页码，前 30 页 + 后 30 页 |
| `dist/store/02-一句话待办-说明书.pdf` | 14 页 | 封面 + 目录 + 概述 + 运行环境 + 功能说明 + 技术架构 + 版本信息，含 5 张界面截图 |
| 身份证正反面 | — | 自己扫描，见下方 C |

> 源程序是用脚本从 `app/src/main/kotlin/` 直接抽的（`build/store/gen_manual.py` 可复现说明书），
> 代码改了要重新生成一次，保证与提交的 APK 一致。

**A. 源程序（已生成）**

- 前 30 页 + 后 30 页，每页 **50 行**代码（共 60 页）
- 页眉写着 `一句话待办 V1.0` + 页码
- 超过 90 字符的长行做了折行续排，不会撑破版心

**B. 软件说明书（已生成）**

- 14 页，图文并茂
- ⚠️ 2026 年起是「有限实质审查」，会做**功能—代码—文档三重校验**：
  说明书里写的功能，代码里必须真有；截图里的界面，要和说明书对得上

**C. 身份证明**

- 身份证正反面扫描件（清晰、不反光、四角完整）
- 手机拍照也行，存成 PDF 或 JPG

6. **上传操作**（这一步就是你在问的「上传 PDF 怎么弄」）

版权保护中心是**全程线上提交**，不需要邮寄纸质材料。具体：

```
登录 ccopyright.com.cn → 「软件登记」→「计算机软件著作权登记」→ 我要登记
  ↓
第一步：填写软件基本信息
        软件全称「一句话待办」、版本号「V1.0」、开发完成日期 2026-10、
        首次发表日期选「未发表」、权利取得方式「原始取得」、开发方式「独立开发」
  ↓
第二步：上传材料（页面上的「上传附件」按钮）
        · 源程序      → 选 01-一句话待办-源程序.pdf
        · 文档        → 选 02-一句话待办-说明书.pdf
        · 证明文件    → 身份证正反面（可合成一个 PDF）
        每个文件都有独立的上传按钮，传完会在列表里显示文件名和大小
  ↓
第三步：在线确认申请表
        系统根据你填的信息生成申请表 PDF，核对无误后勾选承诺、电子签名
  ↓
第四步：提交 → 等受理通知书（约 3~5 个工作日）
```

**上传时容易踩的坑：**

| 坑 | 说明 |
|---|---|
| 文件名带空格/特殊符号 | 系统偶发上传失败，改成纯中文或纯英文名再传 |
| PDF 是扫描件且很糊 | 会被要求补正。我们的两个 PDF 是矢量文字，不存在这个问题 |
| 文件大小 | 单个文件通常限制 100 MB，我们的 0.5 MB / 2 MB，远低于上限 |
| 传错文件 | 提交前可以删除重传；**提交后**再改要走补正流程，很麻烦 |
| 浏览器 | 用 Chrome / Edge，别用 IE 或某些国产浏览器兼容模式 |

7. **提交** → 等受理通知书（约 3~5 个工作日）
8. **受理后 30 个工作日** → 审查通过 → 下载电子证书

### 卡点提醒

- **名称一旦登记就不能随便改**，改名要重新登记。所以「一句话待办」这个名字，提交前最后确认一次。
- 材料被要求「补正」很常见（多半是说明书太薄或代码页眉不规范），补正有 30 天期限，别错过。
- 受理通知书可以先拿去商店后台占位（部分平台认受理通知书），但 vivo 最终要证书。

## ② vivo 开发者账号

### 去哪

https://dev.vivo.com.cn

### 怎么做

1. **注册** → 选择「**个人开发者**」（不是企业）
2. **实名认证**：
   - 身份证正反面照片
   - 手持身份证照或人脸核验
   - 手机号验证
3. 等审核 **1~2 个工作日**（邮件通知）
4. 认证通过后 → 「应用管理」→「创建应用」

### 创建应用时填什么

| 字段 | 填什么 | 注意 |
|---|---|---|
| 应用名称 | **一句话待办** | 必须与软著名称、APK 内 `app_name` 三处完全一致 |
| 包名 | `com.lirui.oneline` | 填错无法改，核对三遍 |
| 应用分类 | 实用工具 → 效率 | |
| 资费方式 | 免费 | |
| 一句话简介 | 一句话记下所有待办，日期时间自动解析 | 5~16 字 |
| 应用介绍 | ≥50 字，从 README 首段改写 | 不能与新版说明相同 |
| 新版说明 | 首个商店版本，支持一句话解析与精确提醒 | ≥5 字 |

### 要上传的素材

| 素材 | 规格 | 现状 |
|---|---|---|
| 图标 | 512×512、直角、≤500 KB、**不带透明通道** | `docs/icon.png` 尺寸合规，需导出无 alpha 版 |
| 截图 | 3~5 张、**1080×1920**、全部竖图、≤2 MB | ⚠️ 现有 1080×2308~2400，需重做 |
| APK | `dist/todo-1.0.0.apk` | ✅ 已就绪 |

### 权限说明怎么填

后台有「权限说明」输入框，逐条写（可直接复制）：

| 权限 | 说明 |
|---|---|
| 通知 | 待办到点提醒，用户可在系统设置关闭 |
| 精确闹钟 | 待办需在用户设定的精确时刻响铃；非精确闹钟会被系统延迟，属核心功能 |
| 开机自启 | 重启后重建已设定的提醒，否则重启会丢提醒 |
| 忽略电池优化 | 仅在用户于「提醒可靠性」页主动点击时跳转系统白名单页，避免后台被清理导致漏提醒，不在启动时自动弹出 |
| 前台服务 | 可选的后台常驻通知，用于及时响应提醒通知上的「完成/撤回」，用户可随时关闭 |

### 隐私政策 URL 填什么

需要**公网可访问的网址**。

**已经生成好了网页**：`dist/store/03-隐私政策.html`
直接把这一份传到博客（例如放到 `blog.zuiges.com/privacy`），后台填这个 URL 即可。
文件是单文件、无外部依赖，浅色/深色自动适配，手机打开也正常。

> 应用内的隐私政策是内嵌文本，不依赖这个链接；这个 URL 只是给商店后台填表用。

## ③ App 备案（先确认要不要办）

### 先别急着办

本应用**不申请任何网络权限**，不提供互联网信息服务。按工信部口径，这类纯单机应用
理论上不属于备案对象。但平台表单是否强制必填，得看到后台才知道。

**判断步骤**：

1. 走完 ② 的「创建应用」
2. 填到「资质」这一步，看「App 备案号」是必填还是选填
3. **选填** → 直接跳过，不用办
4. **必填** → 先联系 vivo 在线客服，说明：
   > 我的应用是纯单机工具，未申请 INTERNET 权限，不提供任何互联网信息服务，
   > 请问 App 备案号是否必须提供？
5. 客服说必须办 → 再往下看

### 真要办的话

| 项 | 内容 |
|---|---|
| 网址 | https://beian.miit.gov.cn （工信部政务服务平台） |
| 关键限制 | **个人不能直接提交，必须通过「接入服务商」** |
| 免费吗 | 官方免费，但接入商可能要求你有服务器/备案服务码 |
| 周期 | 管局审核 20 个工作日内（实际 7~15 天） |

**这就是砍掉联网的最大好处**：不联网就不需要境内接入商，不用为了备案去买服务器。

## ④ 提交审核

材料齐了（软著证书 + 素材 + 隐私政策 URL）之后：

1. 后台补齐资质 → 上传 APK
2. 提交审核 → **1~2 个工作日**出结果
3. 通过 → 自动上架；被拒 → 按驳回理由改，改完重提

### 常见驳回理由 & 应对

| 驳回理由 | 应对 |
|---|---|
| 截图分辨率不符 | 重截 1080×1920 |
| 应用名与软著不一致 | 统一三处名称 |
| 隐私政策打不开 | 换稳定链接 |
| 权限说明不清晰 | 按上面表格重写 |
| 图标有白边/透明 | 导出无 alpha 的直角图 |

## ⑤ 一次材料，五家通用

vivo 通过后，华为 / 小米 / OPPO / 应用宝用**同一套材料**再投一遍：

- 软著证书：同一个应用可以复用（vivo 3.1.2 禁的是"一份软著用在不同应用"）
- 备案号：同一个
- 素材：同一套
- 只是各平台要单独注册开发者账号（都免费）

**建议顺序**：vivo（审核快）→ 华为 → 小米 → OPPO → 应用宝（功能完善度要求最高）。
