## 一、总则

「一句话待办」是一款本地待办事项管理工具。你的待办、专注记录、设置全部只存在设备本地。
本应用**不收集、不上传、不共享你的任何个人信息**，没有账号体系，不要求注册登录。

main 分支自 **v1.0.14** 起恢复了应用内检查更新，因此**会发起网络请求**，但用途只有
「读取公开的版本发布信息」与「下载你主动选择的新版安装包」，详见第四节。

## 二、我们不收集任何个人信息

本应用没有账号体系，不要求注册、登录，也不需要手机号、邮箱或任何身份信息。

- ❌ 不收集设备标识符（IMEI、Android ID、OAID、MAC 地址、序列号等）
- ❌ 不收集位置信息
- ❌ 不读取通讯录、短信、通话记录
- ❌ 不访问相机、麦克风、相册
- ❌ 不收集应用使用行为、崩溃日志、统计数据
- ❌ 不集成任何第三方统计、广告、推送或社交 SDK
- ❌ 不向任何服务器上传待办、专注记录、设置项或备份文件内容

除检查更新 / 下载安装包外，全部功能均可离线使用。

## 三、权限清单及用途

| 权限 | 用途 | 是否可拒绝 |
|---|---|---|
| 通知（POST_NOTIFICATIONS） | 待办到期时发送提醒通知 | 可拒绝，拒绝后收不到提醒，其余功能正常 |
| 精确闹钟（SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM） | 让提醒在设定时刻响铃 | 可拒绝，拒绝后提醒可能延迟 |
| 开机自启（RECEIVE_BOOT_COMPLETED） | 重启后重建已设定的提醒 | 可拒绝 |
| 忽略电池优化（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS） | **仅在你主动点击「提醒可靠性」页按钮时**跳系统白名单页，不会自动弹出 | 可拒绝 |
| 前台服务（FOREGROUND_SERVICE / SPECIAL_USE） | 可选常驻通知，默认开启，可在设置里随时关闭 | 可关闭 |
| **网络（INTERNET / ACCESS_NETWORK_STATE）** | 仅用于检查更新与下载更新包，见第四节 | 可拒绝，拒绝后只是无法检查更新，其余功能正常 |
| **安装未知应用（REQUEST_INSTALL_PACKAGES）** | 仅当你点「下载更新」后，把已下载的 APK 交给**系统安装器**，由你确认安装 | 可拒绝，拒绝后可改用浏览器手动下载 |
| **前台服务 · 数据传输（FOREGROUND_SERVICE_DATA_SYNC）** | 下载更新包期间保活，避免切走 / 锁屏导致下载中断 | 可拒绝 |

**本应用不申请**：位置、通讯录、短信、通话记录、相机、麦克风、设备标识、外部存储读写等权限。
本应用**不能静默安装**任何应用 —— 安装的最后一步始终是系统界面，必须由你本人确认。

## 四、网络请求说明（main 分支专有）

本应用只向下列地址发起 `HTTPS` 请求：

| 时机 | 目标 | 发送什么 | 收到什么 |
|---|---|---|---|
| 冷启动自动检查一次；或你在「关于」页点「检查更新」 | `api.github.com/repos/zuige66/todo/releases/latest`（GitHub 官方 API） | 一个 GET 请求，只带 `User-Agent: Oneline-Android` 与 `Accept` 头；**不含任何本机数据、账号、设备标识或待办内容** | 公开的 release JSON：版本号、更新日志、APK 资产直链 |
| 主源不可达 / 被限流（403、429）时兜底 | `blog.zuiges.com/downloads/oneline/latest.json`（自有静态站） | 同上 | 同版本信息与 APK 直链 |
| 你在弹窗里点「下载更新」 | 上一步结果里的那条 APK 资产直链 | 文件下载请求 | APK 文件本身 |

明确不做的事：

- ❌ 不上传待办、设置、专注记录、备份文件或任何使用数据；不存在后台心跳、埋点、遥测或推送
- ❌ 不向第三方共享任何数据；GitHub / 自有静态站只看到一次普通的公开内容 GET 请求
- ❌ 不自动下载、不自动安装：下载必须由你点击触发，安装必须由你在系统界面确认
- ❌ 检查失败（无网 / 超时 / 限流）时静默失败，不弹错、不影响任何本地功能
- 「关于」页的 GitHub / Issues / 博客链接走系统 `ACTION_VIEW` 交给浏览器，联网的是浏览器

> 历史：v1.0.0 为国内商店上架曾整体下线自更新并移除 INTERNET 权限；
> v1.0.14 起 main 恢复，**合规分支仍保持下线状态**。

## 五、你的数据存储在哪里

你的全部待办数据（标题、详情、日期、时间、重复规则、完成状态、设置项）均存储于：

**你设备本地的应用私有存储目录**（Android 应用沙盒内，其他应用无法读取）。

- 数据**不会**上传到任何服务器
- 数据**不会**同步到云端
- 本应用已关闭系统自动备份（`allowBackup=false`），数据不会被备份到云端

**你主动发起的本地导出**（v1.0.11 起）：你可以在「设置 → 数据」把待办（含归档）、
专注记录与设置项导出到一个**由你在系统文件选择器里亲自选定**的文件，也可以从该文件恢复。

- 该文件是**明文 JSON**，任何拿到文件的人都能读取其中的内容，请自行妥善保管
- 本应用只对你选中的这一个文件写入或读取字节，**不上传、不读取其它文件**；
  文件保存在哪里、是否被你所选的文件提供者同步，由你决定，与本应用无关
- 本应用**不申请存储读写权限**；导出不经过任何服务器
- 系统自动备份仍为关闭状态，此功能不改变 `allowBackup=false`

**删除方式**：

| 操作 | 效果 |
|---|---|
| 在应用内删除单条待办 | 该条数据立即从本地数据库删除 |
| 在系统设置中「清除数据」 | 全部待办与设置立即删除 |
| 卸载本应用 | 全部数据随应用一并删除，**不可恢复** |
